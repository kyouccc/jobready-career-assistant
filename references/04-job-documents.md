# 04 · 求职文书生成

## 通用原则

1. **一页以内**（求职信 300–400 字，邮件 150–250 字），HR 不会读长文。
2. **每句话都要有专属信息**。删掉「贵公司是行业领先企业」这类放到任何公司都成立的话 —— 这是判断文书是否模板化的唯一标准。
3. **先给成品，再给说明**。输出完整可复制的正文，其后附「替换清单」（哪些 `【】` 需要用户填写）与「个性化建议」。
4. **语域匹配**：国内企业用中文商务体；外企或英文 JD 用英文，英文文书避免中式直译（不要 `I am writing to apply for...` 开头堆三段）。
5. **事实一致**：文书中的经历、时间、数据必须与简历一致，不得为了好看而夸大。

---

## 1. 求职信（Cover Letter）

**使用场景**：外企、咨询、部分国企、内推邮件附件、需要说明「为什么是我」的场合。国内互联网大厂网申通常不需要，但内推邮件正文常按此写。

**结构（四段）**：

| 段落 | 内容 | 字数 |
|---|---|---|
| 开头 | 应聘岗位 + 信息来源 + 一句话定位自己 | 40–60 |
| 匹配论证 | 挑 2 个与 JD 最强相关的经历，各一句量化成果 | 120–180 |
| 动机 | 为什么是这家公司/这个团队（要有具体理由，如产品、技术方向） | 60–80 |
| 结尾 | 表达期待 + 联系方式 | 30–40 |

**范例**：

```
尊敬的【公司】招聘团队：

您好。我通过【内推人/官网/校招宣讲】了解到贵团队正在招聘【CV 算法工程师（实习）】，
我是【学校】【专业】2025 级本科生，主要方向为计算机视觉，希望申请该岗位。

在【项目名】中，我独立完成【具体工作】，通过【技术方案】，将【指标】从【X】提升至【Y】。
另一段经历中，我基于【技术栈】实现了【产出】，【量化结果】。这些经历让我具备了
JD 中要求的【关键词 1】【关键词 2】的实际动手经验。

我关注贵团队在【具体产品/技术方向】上的进展，尤其是【具体细节】，这与我在
【相关方向】上的积累方向一致，希望能在此方向上继续深入。

我的简历见附件，期待有机会与您进一步沟通。感谢您的时间。

【姓名】｜【手机】｜【邮箱】
```

**避坑**：不要罗列简历全部内容（HR 会读简历）；不要写「我从小就对计算机感兴趣」。

## 2. 面试感谢信

**使用场景**：面试后 24 小时内发送（越早越好）。外企/注重礼仪的团队加分明显，国内多数场景属锦上添花但不减分。

**结构**：致谢（1 句）→ 补充面试中未答好的一点（1–2 句，体现反思能力）→ 重申匹配（1 句）→ 祝福（1 句）。总长 150 字以内。

**范例**：

```
【面试官姓名】老师，您好：

感谢您今天抽出时间与我交流【岗位名】的面试，您关于【面试中聊到的具体话题】
的提问让我对岗位的实际工作有了更清晰的认识。

面试中我关于【未答好的问题】的回答不够完整，补充一点想法：【一句话补充】。

我对【岗位/团队方向】的兴趣在交流后更加明确，期待有机会加入。

祝您工作顺利！

【姓名】
```

## 3. Offer 接受函（Acceptance Letter）

**结构**：明确接受（岗位+公司）→ 确认关键条款（入职日期、地点、薪资结构、试用期）→ 表达期待 → 联系方式。

**范例**：

```
尊敬的【HR 姓名/招聘团队】：

您好。感谢贵公司提供的录用机会。我正式接受【公司】的【岗位名称】录用，
并确认以下事项：

· 入职日期：【YYYY 年 MM 月 DD 日】
· 工作地点：【城市/办公地址】
· 薪资结构：【月薪 × 月数 + 年终奖口径】
· 试用期：【时长】

如有需要提前准备的入职材料，请随时告知。我会按时报到并做好入职准备。
期待加入团队。

【姓名】｜【手机】｜【邮箱】
【日期】
```

**避坑**：一旦发出即为承诺，发出前确认没有其他 offer 在等；若有条款需协商，先谈判再发接受函。

## 4. Offer 拒信（Decline Letter）

**结构**：致谢 → 明确婉拒 → 一句中性理由（不贬低、不细说其他 offer 待遇）→ 保持关系。

**范例**：

```
尊敬的【HR 姓名】：

您好。非常感谢贵公司给予的录用机会，以及在招聘过程中投入的时间与耐心。

经过慎重考虑，我因【个人职业规划方向 / 岗位方向匹配度】的原因，
决定暂时无法接受本次录用，恳请谅解。

贵公司【一句具体的好话，如：在 XX 领域的技术积累】给我留下了深刻印象，
希望未来还有机会合作。再次感谢！

【姓名】
```

**避坑**：不要写「另一家给的钱更多」；不要已读不回（行业圈子小，尤其同一城市同赛道）；不要拖延到最后一天才回。

## 5. 求职咨询邮件

**使用场景**：向 HR 询问投递进展、向学长/从业者做信息访谈、向上级或导师请求内推。

**结构**：自我介绍（一句）→ 明确诉求（一句，越具体越好）→ 已做的准备（体现诚意）→ 时间预期 + 致谢。

**范例（询问进展）**：

```
【HR 姓名】老师，您好：

我是【姓名】，于【日期】投递了【岗位】，并于【日期】完成【笔试/一面】。
想请问目前流程是否有进一步安排？如需补充材料我可以随时提供。

感谢您的时间！

【姓名】｜【手机】
```

**范例（请求信息访谈）**：

```
【姓名】学长，您好：

我是【学校】【专业】的【姓名】，通过【渠道】了解到您在【公司/岗位】工作。
我目前正在准备【方向】的求职，特别想了解【一个具体问题，如：该岗位日常工作中
最核心的技术能力是什么】。

我提前读了【相关材料/产品/论文】，目前的初步理解是【一句话】，
不知是否理解有偏差。若您方便，希望能占用您 15 分钟请教，也随时可以线上。

感谢！
```

**避坑**：不要问「你们招人吗」这种百度能查到的问题；一次只问一个核心问题；对方没回不要连续追问超过一次。

## 6. 实习证明（开具申请 / 内容模板）

**使用场景 A：向实习单位申请开具证明**

```
【HR / 直属主管】您好：

我是【部门】【姓名】，实习期间为【起止时间】，已完成【核心工作/交接】。
因【学校实习学分认定 / 校招材料提交】，需要一份实习证明，
需包含：姓名、身份证号（如需）、实习起止时间、岗位名称、主要工作内容、单位盖章。

请问我需要提供什么材料、走什么流程？如需模板我可以先拟一版供您修改。
感谢！

【姓名】｜【部门】｜【联系方式】
```

**使用场景 B：证明内容模板（供单位参考）**

```
实习证明

兹证明【姓名】（身份证号：【】），于【YYYY 年 MM 月 DD 日】至
【YYYY 年 MM 月 DD 日】在我单位【部门】实习，担任【岗位名称】，
主要工作内容为：
1. 【工作内容一】
2. 【工作内容二】
3. 【工作内容三】

实习期间该同学工作态度端正，能按时完成分配任务，表现【良好/优秀】。

特此证明。

【单位名称】（盖章）
【YYYY 年 MM 月 DD 日】
```

**避坑**：证明内容要写**具体工作**而非「表现良好」四字，否则学校学分认定或背调时说服力不足；务必确认盖章单位与简历填写一致。

---

## 输出要求

生成任一文书时，输出三部分：

1. **成品正文**（完整，可直接复制）
2. **替换清单**（列出所有 `【】` 字段及填写建议）
3. **个性化建议**（1–3 条，指出哪些句子最该按用户真实情况替换，替换后效果差异在哪）
