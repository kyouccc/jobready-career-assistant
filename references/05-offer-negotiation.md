# 05 · Offer 对比与谈判

## 一、七维对比表

输入 2–3 个 offer，按下表逐维填写。**信息不全时先追问，不要留空或猜**（尤其年终奖月数、公积金比例、试用期工资）。

| 维度 | Offer A | Offer B | Offer C | 说明 |
|---|---|---|---|---|
| ① 基本工资 | 月薪 ¥X × 12 | | | 注明税前 |
| ② 年终奖 | X 个月 / 保证与否 | | | **是否写进合同**是关键 |
| ③ 五险一金 | 基数 + 公积金比例 | | | 基数是否按全额 |
| ④ 试用期 | 时长 + 工资比例 | | | 法定 ≤6 个月且 ≥80% |
| ⑤ 加班情况 | 作息 + 周末 + 加班费 | | | 影响实际时薪 |
| ⑥ 成长空间 | 团队/技术/晋升/带人 | | | 定性评估，给 1–5 分 |
| ⑦ 城市生活成本 | 房租 + 通勤 + 落户 | | | 用实际数字 |

### 换算口径（必须计算，不能只比月薪）

```
年度现金总额 = 月薪 × 发放月数
             + 年终奖（按「保证部分」计入；浮动部分单独标注）
             + 各类补贴（餐补/房补/交通/通讯 × 12）
             + 一次性收入（签字费/安家费，标注为一次性）

公积金年收益 = 月薪 × 公积金比例 × 2 × 12   ← 个人+公司双边，可提取/还贷
月度可支配   ≈ 月薪 × (1 − 个税与社保个人缴纳比例) + 公积金个人部分 − 房租 − 通勤 − 生活支出

实际时薪 = 年度现金总额 ÷ 年工作小时数
         （按 250 工作日 × 实际日均工时计算；「大小周/996」会显著拉低）
```

> **最容易被忽略的一条**：加班与公积金。两份月薪差 2000 的 offer，若一份是 965 且公积金 12%，另一份是大小周且按最低基数缴纳，前者实际收益通常更高。务必把「实际时薪」算出来给用户看。

**优先用脚本算，不要心算**：拿到 2 个及以上 offer 的具体数字后，调用 `scripts/offer_calc.py`（纯标准库，无依赖）：

```bash
python scripts/offer_calc.py --demo                         # 先看示例输入格式
python scripts/offer_calc.py offers.json --format markdown  # 输出 Markdown 对比表
```

脚本会输出上表全部指标，并自动区分「保证现金」与「浮动现金」。若运行环境不支持代码执行，则手动套用上方公式，**并在回复中展示计算过程**供用户复核。

### 成长空间的评分锚点

成长空间是七维里**唯一无法量化**的维度，必须给判断依据，不能只给分数：

| 分数 | 技术成长 | 团队与带人 | 晋升机制 |
|---|---|---|---|
| 5 | 团队做行业前沿方向，有技术沉淀与对外分享 | 有明确 mentor 制，直属上级愿意带人 | 晋升通道透明，有公开职级标准 |
| 4 | 方向主流，能接触完整技术链路 | 团队规模适中，有代码 review 文化 | 有定期晋升窗口 |
| 3 | 方向常规，以业务交付为主 | 团队成熟，带人靠自觉 | 晋升看机会，无固定节奏 |
| 2 | 技术栈陈旧或高度定制化，迁移性差 | 团队人手紧，无暇带人 | 晋升通道不清晰 |
| 1 | 外包 / 驻场性质，无技术积累 | 无固定团队 | 无 |

**执行要求**：
- 判断依据必须来自**可核实的信息** —— 面试中问到的团队规模与汇报线、公开的技术分享、
  员工评价等。不要把「公司名气大」等同于成长空间高。
- **信息不足时给区间并说明缺口**（如「3–4 分，取决于你被分到哪个组，建议面试时追问」），
  不要为了填满表格而编造分数。
- 对实习生额外提醒：实习的成长空间主要取决于**带你的那个人**，而不是公司整体。面试时值得直接问
  「我的 mentor 是谁、他目前负责什么方向」。

### 决策辅助

除表格外，输出：
- **一句话结论**：若只能选一个，推荐哪个，核心理由是什么
- **三档情境建议**：看重钱 / 看重成长 / 看重生活平衡，分别选哪个
- **不可逆风险提示**：如「B 公司的年终奖口头承诺未写入合同，历史上兑现率不明」→ 需现场检索公司评价与裁员/欠薪记录

## 二、谈判话术（三阶段）

### 谈判前的三条铁律

1. **先摸清空间**。校招大厂多为标准化定级（如 16 薪 × 定级月薪），**月薪通常不可谈**，可谈的是：职级定档、签字费、股票/RSU、房补、入职时间、实习转正、部门/城市选择。中小公司和小团队，月薪反而有空间。
2. **必须有筹码**。最有效的筹码是**竞争 offer**，其次是**稀缺技能匹配度**。没有筹码时，谈判只会消耗 goodwill。
3. **只谈一次，不反复拉扯**。一次性提出完整诉求，反复议价风险高（存在 offer 撤回与入职后印象受损的真实案例）。

### 阶段一：初谈（探边界，不给死数）

**场景**：HR 问「你的期望薪资是多少？」

**话术模板（有竞争 offer）**：

```
感谢您的认可。我目前对贵公司的岗位非常感兴趣，方向也和我之前的积累很匹配。
在薪资上，我手上有一份【同梯队公司】的 offer，年包大致在【区间】。
考虑到贵公司的平台和成长性，我更看重整体，希望年包能在【略高于现 offer 的区间】，
不知道这个范围是否在贵司的预算内？
```

**话术模板（无竞争 offer）**：

```
我了解到这个岗位在【城市】的校招年包大致在【区间】（参考公开数据）。
结合我的【具体技能/项目匹配点】，我期望年包在【区间中位数偏上】。
具体结构上我比较灵活，更关注【成长空间/部门方向】，薪资可以一起看整体方案。
```

**要点**：先给区间不给单点；先表达意愿再谈钱；把「为什么值这个价」绑定到具体技能与 JD 的匹配上。

### 阶段二：还价（对方压价时的应对）

**场景 A：HR 说「这个薪资超出预算了」**

```
理解，我也知道校招的定级体系相对固定。那我想确认两点：
一是定级是否可以争取到【更高一档】；
二是除月薪外，【签字费 / 房补 / 股票 / 试用期工资比例】是否有调整空间？
如果月薪确实固定，我希望能在这几项上找到平衡。
```

**场景 B：HR 说「你期望太高了，我们只能给 X」**

```
明白，谢谢您坦诚告知。X 与我的预期有一定差距，主要考虑的是【城市生活成本 / 已有 offer 水平】。
如果基本工资确实到顶，能否在【签字费/入职时间/部门选择】上协调？
另外方便的话，能否告知这个定级对应的年终奖与调薪机制？我想把整体方案算清楚再做决定。
```

**要点**：不直接拒绝，先**换维度**（月薪谈不动就谈签字费/职级/福利）；用「把整体方案算清楚」把决策权留在自己手上。

### 阶段三：收尾（成交与确认）

**场景 A：达成一致**

```
谢谢您的协调，这个方案我可以接受。为了后续不出差错，麻烦您把以下内容
在 offer 函中明确：【月薪与发放月数】【年终奖口径】【签字费金额与发放时间】
【公积金缴纳基数与比例】【试用期时长与工资比例】【入职日期】。
确认无误后我会尽快回复正式接受函。
```

**场景 B：需要时间考虑**

```
非常感谢，我对这个方案整体是认可的。因为我还有一个流程在推进，
希望能有【3–5 个工作日】做最终决定，【具体日期】前一定给您明确答复。
请问这个时间可以吗？
```

**场景 C：最终低于底线，决定婉拒**

```
非常感谢贵公司的诚意和这段时间的沟通。综合考虑后，我目前的条件与我的
规划还有一定差距，这次只能遗憾放弃。希望未来还有合作机会。
（不透露具体差距数字，不比较其他公司待遇）
```

## 三、避坑清单

- ❌ **虚报已有 offer**。行业 HR 圈子小，同城同赛道互相打听很常见，一旦被识破直接失去机会。
- ❌ **拿到口头承诺不落纸**。所有承诺（年终奖月数、股票、调薪、转正）必须在 offer 函或邮件中留痕。
- ❌ **反复议价**。提一次完整诉求，得到答复后再决定接受或拒绝。
- ❌ **拖到 deadline 最后一天**。会损害雇主印象，也压缩了自己的缓冲空间。
- ❌ **只比月薪**。必须比「年度现金总额 + 公积金 + 实际时薪」。
- ⚠️ **在校生注意**：实习转正 offer 与校招 offer 的口径不同，需单独确认转正定级规则。

## 输出格式

1. 七维对比表（Markdown 表格）
2. 换算结果表（年度现金、公积金年收益、月度可支配、实际时薪）
3. 结论与三档情境建议
4. 按用户当前阶段（初谈/还价/收尾）给出的可直接使用话术
5. 主动询问：「需要我帮你把谈判过程整理成一份沟通脚本，或者模拟一次 HR 议价对话吗？」
