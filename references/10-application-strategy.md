# 10 · 投递策略与时间线

> 这是求职链路里最容易被忽略、却最影响结果的一环。
> **简历写得好但投递节奏错了，等于把好牌打烂。**

## 一、底层认知

**求职是概率游戏。** 单家公司的通过率通常在个位数到 20% 之间，所以必须靠**数量 × 节奏**取胜。

**但不能无序海投。** 因为存在冷冻期机制 —— 投错了顺序，会浪费掉最想去的机会。

**目标**：在有限时间内，用最低的机会成本，拿到最多的面试机会。

## 二、冷冻期：最重要的一个机制

**定义**：同一公司在同一招聘周期内，候选人笔试或面试未通过后，会有一段时间不能再投。
常见为 6–12 个月，**各公司政策不同且会调整**。

**为什么它决定了投递顺序**：

- 如果你把最想去的公司投在第一位，一旦挂在笔试或一面，可能整个招聘季都没法再投它。
- 正确做法是**用同类型、但意向度较低的公司先练手** —— 摸清题型、难度、面试风格，
  再把最想去的公司排在后面。

**但要注意两个反制因素**：
1. **提前批名额有限**，排太晚可能 HC 已经用完。
2. 部分公司的提前批**不占正式批机会**（挂了还能投正式批），这类公司可以放心早投。

> **执行要求**：**不得凭记忆断言某家公司的冷冻期是几个月。**
> 这是会变的具体政策，必须现场检索该公司的招聘公告或询问 HR。
> 可以给出的是机制与判断框架，具体数字要用户自行核实。

## 三、时间线

### 在校生找实习

| 类型 | 投递窗口 | 入职时间 | 特点 |
|---|---|---|---|
| 暑期实习 | 3–5 月 | 6–8 月 | 竞争激烈，**有转正机会**，是校招的主要入口 |
| 日常实习 | 全年滚动 | 随时 | 门槛低于暑期实习，**低年级应优先走这条** |
| 秋招提前批 | 7–8 月 | 次年入职 | 名额好，部分不占正式批机会 |
| 秋招正式批 | 9–10 月 | 次年入职 | 主战场，岗位最多 |
| 春招 / 补录 | 次年 3–5 月 | — | 捡漏，岗位少但竞争也小 |

**低年级（大一/大二）策略**：优先投**日常实习**。暑期实习通常要求有项目或实习经历，
低年级直接投命中率低；日常实习更看「能干活、时间稳定」，反而容易进。

### 投递节奏建议

1. **先练手**：用 3–5 家意向度中等的公司摸清流程与题型。
2. **再主攻**：集中投意向度高的公司。
3. **留后手**：保留 2–3 家作为保底，不要全部押在头部公司。

## 四、投递管理表

**必须建表记录**，否则一定会出现「忘了哪家投过、哪家该催」的情况：

| 公司 | 岗位 | 投递日期 | 渠道 | 当前状态 | 下一步动作 | 冷冻期截止 |
|---|---|---|---|---|---|---|
| | | | 内推 / 官网 / 平台 | 已投 / 简历筛 / 笔试 / 一面 / 二面 / HR 面 / offer | | |

**状态流转**：`已投 → 简历筛 → 笔试 → 一面 → 二面 → HR 面 → offer → 已接受/已婉拒`

建议每周固定一天更新一次状态，并检查「下一步动作」栏里有没有过期待办。

## 五、渠道优先级

| 优先级 | 渠道 | 优势 | 注意 |
|---|---|---|---|
| 1 | **内推** | 简历必被看到，部分公司免笔试或加速流程 | 内推人不等于保过，仍要走完整流程 |
| 2 | 公司官网直投 | 信息最准，无中间商 | 简历可能石沉大海 |
| 3 | 招聘平台（BOSS / 猎聘等） | 可直聊 HR，反馈快 | 岗位真实性需甄别，注意外包 |
| 4 | 校园宣讲会 | 可现场投递、当面沟通，印象分高 | 时间地点固定，需提前查行程 |

## 六、内推怎么找

**优先级从高到低**：
1. 学长学姐（最有效，且能问内部信息）
2. 校友群、实验室、导师推荐
3. 技术社区（CSDN / 掘金 / 知乎 / GitHub）上活跃的从业者
4. 公开的内推码 / 内推群（效果最弱，但聊胜于无）

**内推请求话术模板**：

```
【称呼】您好：

我是【学校】【专业】的【姓名】，通过【渠道】了解到您在【公司】工作。
我正在准备【岗位方向】的求职，想请您帮忙内推【具体岗位名称】（岗位链接/编号：【】）。

我的匹配点：【一句话 + 一个可验证的成果，如「独立完成 XX 项目，指标从 X 提升到 Y」】。
简历见附件。若您方便，我可以把岗位要求与我的经历做一份对应说明，方便您转发。

无论结果如何都很感谢！
```

**要点**：一次说清「我是谁 + 投什么岗 + 我的匹配点 + 需要你做什么」。
**不要把简历一扔说「帮我内推一下」** —— 内推人要替你背书，他需要知道推荐理由。

## 七、跟进与催促

| 场景 | 时机 | 频次 |
|---|---|---|
| 投递后无反馈 | 2 周 | 只问一次 |
| 笔试后无反馈 | 2 周 | 只问一次 |
| 面试后无反馈 | 1 周 | 只问一次 |
| 已发 offer 待回复 | 按 offer 函截止日 | — |

**规则：同一环节只催一次。** 连续追问会损害印象，且不会加快流程。

**跟进话术**：

```
【HR/面试官】您好：

我是【姓名】，于【日期】投递/面试了【岗位】。
想请问目前流程是否有进一步安排？如需补充材料我可以随时提供。
感谢您的时间！
```

## 八、被拒后的处理

**先区分是「简历挂」还是「面试挂」** —— 两者应对方式完全不同：

| 类型 | 信号 | 应对 |
|---|---|---|
| 简历挂 | 投递后无笔试邀请 | 简历关键词覆盖不足或岗位错配 → 改简历（见 `01-resume-optimization.md`）、调整岗位方向 |
| 笔试挂 | 有笔试但无面试邀请 | 刷题量不足或输入输出不熟 → 见 `09-written-test-prep.md` |
| 面试挂 | 有面试但无后续 | 表达能力或技术深度问题 → 走面试复盘（见 `03-interview-simulation.md`） |
| 全程无进展 | 投了很多家都没动静 | 可能是简历整体定位问题，或投递渠道有问题 |

**不要做的事**：同一家公司短期内反复投（冷冻期）、把失败归因于「学历不行」而不看具体环节。

## 九、输出结构

当用户提出投递策略相关需求时：

1. **确认**：身份（在校/应届）、目标方向、当前进度（已投几家、到哪一步）、可用时间
2. **给出时间线定位**：现在处于哪个窗口期，还剩多少时间
3. **给出投递顺序建议**：哪些先练手、哪些主攻、哪些保底，并说明冷冻期风险
4. **给一份投递管理表模板**（可直接复制使用）
5. **提醒现场核实**：目标公司的冷冻期政策与 HC 情况

> **与其他能力的联动**：投递策略是「全流程陪跑」的起点。
> 投递前应完成 `02-jd-analysis.md`（选岗）与 `01-resume-optimization.md`（改简历）。
